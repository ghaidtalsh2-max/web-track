منصة تفاعلية متكاملة لأعضاء وقادة مسار تصميم وتطوير الويب في نادي قوقل للطلبة المطورين (GDG on Campus Taif University). تجمع المنصة بين الهوية البصرية الرسمية لقوقل، معمل أكواد حي، لوحة تحكم إدارية للقائد، معرض أعمال، وبوابة استفسارات مباشرة.

🔗 **الرابط المباشر للمنصة على Vercel**: [https://web-track-kappa.vercel.app](https://web-track-kappa.vercel.app)

---

## ✨ المميزات الرئيسية (Core Features)

* **🔐 نظام تسجيل دخول حقيقي ومحصن (Production Authentication)**:
  * تسجيل دخول رسمي برقم العضوية (ID) أو اسم المستخدم.
  * التحقق من الهوية وحماية الجلسات محلياً (`atomic session validation`) لمنع الأخطاء والشاشات البيضاء.
  * تخصيص الملف الشخصي وتحديث النبذة التعريفية (Bio) والروابط المهنية (GitHub, LinkedIn).

* **🧪 معمل الويب التفاعلي (Interactive Web Lab)**:
  * محرر أكواد متقدم (HTML / CSS / JS) مع Syntax Highlighting وتجربة محررات برمجية واقعية.
  * معاينة حية وفورية في نافذة عرض مخصصة.
  * لوحة أدوات وأيقونات ثلاثية الأبعاد (3D Floating Controls) لتجربة مستخدم ممتعة وسلسة.

* **👑 لوحة تحكم القائد (Leader Dashboard)**:
  * متابعة فورية لقائمة الأعضاء، وتحديث المهارات وحالات التفاعل.
  * إدارة الاستفسارات الواردة والرد المباشر عليها.
  * إحصائيات بصرية ذكية لمستوى إنجاز المسار ومشاريع الأعضاء.

* **🎨 هوية بصرية متميزة (Google & GDG Brand Identity)**:
  * تصميم بألوان قوقل الأربعة المتناسقة (الأزرق، الأحمر، الأصفر، الأخضر).
  * خطوط **ثمانية (Thmanyah Sans)** الرسمية لتجربة قراءة عربية فائقة الجمال.
  * انترو دخول سينمائي بتموجات هندسية انسيابية مريحة للعين.
  * دعم الوضع الليلي (Dark Mode) والوضع النهاري مع خلفيات زجاجية (Glassmorphism).

* **💬 بوابة الاستفسارات التفاعلية (Direct Inquiries)**:
  * إمكانية إرسال الأعضاء لأي تساؤلات برمجية أو أكاديمية مباشرة للقائد مع تصنيف الحالة (جديد / تم الرد).

* **🏆 معرض المشاريع والتحديات (Showcase & Challenges)**:
  * عرض إبداعات أعضاء المسار وتصويت المجتمع التقني.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Framework**: React 19 (TypeScript)
* **Build Tool**: Vite 6
* **Icons**: Lucide React
* **Styling**: Vanilla CSS + Tailwind CSS (Google/GDG Curated Palette)
* **Typography**: Thmanyah Sans Official Arabic Fonts
* **State & Storage**: Resilient Atomic LocalStorage Store
* **Deployment**: Vercel Serverless

## 🚀 التشغيل محلياً (Local Development)

```bash
# 1. استنساخ المستودع
git clone git@github.com:ghaidtalsh2-max/web-track.git
cd web-track

# 2. تثبيت الحزم
npm install

# 3. تشغيل بيئة التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:5173`
